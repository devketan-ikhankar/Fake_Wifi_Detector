🔧 STEP-BY-STEP INSTALLATION
═══════════════════════════════════════════════════════════════

STEP 1: Extract Files
----------------------
Extract ALL files from the zip to a folder.
You should see this structure:

    WiFiDefender/
    ├── app.py
    ├── wifidefender.db
    ├── templates/
    │   ├── login.html
    │   ├── register.html
    │   ├── dashboard.html
    │   └── history.html
    ├── SETUP.txt (this file)
    └── requirements.txt

⚠️  CRITICAL: The "templates" folder MUST be in the same 
    directory as app.py or you'll get FileNotFoundError!


STEP 2: Install Python Dependencies
------------------------------------
Open Command Prompt or Terminal in the WiFiDefender folder:

    pip install flask flask-cors

Or use the requirements.txt:

    pip install -r requirements.txt


STEP 3: Run the Application
----------------------------
Windows:
    python app.py

Mac/Linux:
    sudo python3 app.py
    (sudo needed for WiFi scanning)


STEP 4: Open in Browser
------------------------
Navigate to:
    http://localhost:5000

You should see the login page!


📋 FIRST TIME SETUP
═══════════════════════════════════════════════════════════════

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

ERROR: "FileNotFoundError: templates/login.html"
SOLUTION: Make sure templates folder is next to app.py

ERROR: "No module named 'flask'"
SOLUTION: Run: pip install flask flask-cors

ERROR: "No networks found"
SOLUTION: 
  - Windows: Run Command Prompt as Administrator
  - Mac: Use sudo python3 app.py
  - Linux: Use sudo python3 app.py

ERROR: "Address already in use"
SOLUTION: Another app is using port 5000
  - Close the other app
  - Or change port in app.py (line 665): 
    app.run(port=5001)
